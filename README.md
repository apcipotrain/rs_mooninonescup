# Moon in One’s Cup

基于 Cocos Creator 制作的《滚动的天空》风格单关卡练习项目。

玩家控制小球沿五列地砖道路前进，通过左右移动、跳跃和传送避开危险，并收集关卡中的钻石与皇冠。

整体美术采用“中国山水意境＋简洁几何”，结合青绿山水、琥珀金、月白和桃花色。道具使用可复用的低面数立体网格，保留原有七段背景与关卡规则。

## 操作方式

- 按住鼠标左键并拖动：控制小球左右移动。
- A / D 或左右方向键：控制小球左右移动。
- 初次预览先显示关卡封面，点击“进入关卡”后回到等待输入状态。
- 等待输入时，拖动鼠标或按 A / D、左右方向键：正式开始游戏并播放音乐。
- 等待开始和游戏运行时，均可点击左上角“Ⅱ 设置”打开暂停／设置菜单。
- 暂停菜单中的音量滑条：在 `0～100` 之间调节背景音乐，`0` 为静音；可点击、拖动，或使用 `＋ / −` 每次调整 `1`。
- 点击“继续游戏”：经过 2 秒倒计时后继续。
- 点击“重新开始”：重置关卡，回到等待输入状态，不再打开封面，保留音量设置。
- 点击菜单中的“返回封面”：重置关卡并停止音乐，返回最初的“进入关卡”页面；可再次进入。等待开始时关闭设置会回到等待输入，不启动音乐或继续倒计时。

鼠标用于快速定位，键盘用于微调。

## 已实现功能

### 游戏流程

- 同场景关卡封面：标题 `Moon in One’s Cup`、副标题“青山入盏，踏月而行”、信息 `02:01 · 10 钻石 · 3 皇冠`。
- 封面期间小球不移动、不播放关卡音乐、不接受启动输入；进入按钮点击不会直接启动游戏。
- 封面期间按住的方向键需要松开后重按，避免系统按键重复事件误启动。
- 等待输入后开始游戏。
- 暂停、继续和重新开始。
- 继续游戏时显示精确到一位小数的倒计时。
- 掉落或碰撞后禁止操作，等待 2 秒显示失败界面。
- 到达终点后显示通关界面。
- 游戏内显示关卡进度。
- 仅在胜利和失败界面显示钻石和皇冠收集统计，游戏内 HUD 只显示进度。
- 重新开始时恢复地砖与收集物状态。
- 背景音乐音量自动保存在当前浏览器或运行环境的本地存储中；刷新预览后可恢复。存储不可用时，本次运行内仍可正常调整。

### 道路与控制

- 使用 JSON 配置五列道路。
- 支持手写地砖布局和重复路段。
- 按玩家位置更新道路显示范围。
- 鼠标快速横移时检查经过的路径。
- 球下方没有有效地砖时触发掉落。
- 摄像机跟随小球前进。

### 主题切换

- 七张固定屏幕背景。
- 在 16、32、48、64、80、96 秒切换背景。
- 第七张背景保持到关卡结束。
- 小球材质随背景主题同步切换。
- 普通地砖使用独立的浅色主题，与小球同步切换，通过色相、饱和度和明暗保持区分。
- 重新开始时，背景、小球和普通地砖一起恢复第一段主题。

| 路段 | 时间范围 | 普通道路风格 | 小球配色 |
| --- | --- | --- | --- |
| 1 | 0～16 秒 | 街边灯黄：淡奶金 | 琥珀金 |
| 2 | 16～32 秒 | 红枫栈桥：浅枫红 | 朝霞红 |
| 3 | 32～48 秒 | 白灰石径：月白灰 | 天蓝 |
| 4 | 48～64 秒 | 草色：浅黄草绿 | 青绿 |
| 5 | 64～80 秒 | 幽径：雾青蓝 | 月白 |
| 6 | 80～96 秒 | 世外桃源山色：淡青山绿 | 桃粉 |
| 7 | 96 秒～结束 | 水墨灰：浅宣纸灰 | 墨灰 |

主题时间由玩家前进距离除以前进速度计算，暂停时不会继续推进。玻璃砖保留青蓝识别色，跳跃砖保留橙色识别色。

### 道具与地砖美术

| 对象 | 当前造型与表现 |
| --- | --- |
| 钻石 | 加宽的青蓝切面钻石，平顶、宽腰、尖底，默认底尖贴地 |
| 皇冠 | 连续多边形镂空环带、沿圆周分布的冠齿、金色主体与红色宝石 |
| 山峰 | 青绿、青黛棱面山石，按现有碰撞尺寸适配 |
| 普通地砖 | 浅色砖面、立体倒角、内嵌细槽、内沿亮线与四角 L 形收口 |
| 小玻璃砖 | 半透明青蓝顶面与不透明边缘，优先保证轮廓清楚 |
| 跳跃砖 | 橙色主体，朝前进方向的双箭纹饰 |
| 激光发射器 | 参考原图的遗迹机械独眼：古铜同心装甲、四向遮片、琥珀核心；发射时核心亮起 |
| 传送入口 | 参考原图的沉玉金鲤意象：半透明玉色光团、立体金色游鱼与环绕金纹 |

`PropArt` 在运行时构建网格，复用同类道具的网格和材质，并在最后一个使用者销毁时释放生成资源。普通地砖的边框与砖面合并在同一网格中。原始贴图和预制体资源引用保留，模型显示随原有节点一起隐藏或重置，不新增独立动画计时。

美术升级未改动关卡 JSON 中的地形、障碍坐标与收集物数量，也未调整移动、碰撞、拾取、跳跃、玻璃坍塌、传送和激光判定规则。

## 地砖与独立物体

### 地砖类型

地砖写在 JSON 的 `ground` 字符串中。

| 字符 | 类型     | 规则                       |
| ---- | -------- | -------------------------- |
| `0`  | 空格     | 不提供地面支撑             |
| `1`  | 普通地砖 | 正常通行                   |
| `3`  | 小玻璃砖 | 踩到后延迟坍塌             |
| `5`  | 跳跃砖   | 自动起跳，空中允许左右移动 |

小玻璃砖默认在触发后 `0.36` 秒开始坍塌。

跳跃砖按整块有效区域判断触发。默认越过三行，落在跳板前方第四行中心。

### 独立物体

独立物体通过坐标列表配置，不占用地砖字符。

| 字段        | 内容       | 规则                                     |
| ----------- | ---------- | ---------------------------------------- |
| `mountains` | 山峰       | 碰撞即失败，可以从足够高度越过           |
| `teleports` | 传送入口   | 隐藏球体，向前传送八行，期间禁用左右操作 |
| `lasers`    | 激光发射器 | 接近到前方六行时触发，持续两秒           |
| `diamonds`  | 钻石       | 接触收集范围后消失并计数                 |
| `crowns`    | 皇冠       | 接触收集范围后消失并计数                 |

激光发射器本体始终具有碰撞伤害。

当前激光从发射器沿世界坐标 `+Z` 方向发射，视觉光束按 LaserSystem 的宽、高与范围适配。机械眼浮雕的整体尺寸同样由发射器原有碰撞尺寸适配。

传送入口需要地板，出口允许为空。球到达空出口后按普通掉落处理，不进入暂停菜单。

钻石和皇冠允许配置在没有地板的位置，用于空中路线。每件收集物每次游玩只能拾取一次，传送隐藏期间不拾取。

## 运行项目

1. 使用 Cocos Dashboard 导入项目目录。
2. 使用 Cocos Creator 3.8.8 打开项目。
3. 等待资源导入与脚本编译完成。
4. 打开 `assets/scenes/Main.scene`。
5. 点击编辑器上方的预览按钮。
6. 在封面点击“进入关卡”。此时仍处于等待输入状态。
7. 拖动鼠标或按 A / D、左右方向键正式开始。
8. 如需调整音乐，点击左上角暂停按钮，在暂停菜单中调节音量，然后点击“继续游戏”。

封面、暂停菜单和音量控件由脚本自动创建；现有九类预制体已绑定 PropArt，正常运行无需额外手动绑定。程序生成的道具造型在游戏运行时显示，编辑器未预览时仍可能显示保留的旧模型。

Web Desktop 使用 `build-templates/web-desktop/index.ejs` 自定义模板：保持与设计分辨率 `1280 × 720` 一致的 16:9 画面，按浏览器可用宽高等比缩放并居中，比例不同时留黑边。网页不再使用默认的 1280 × 960 固定容器、标题和页脚，避免构图变化和页面滚动。调整浏览器窗口时会同步更新游戏容器尺寸；模板在重新构建时继续生效。部署时应上传最新的 `build/web-desktop` 目录内容。

如果出现缺失绑定，请检查：

- Player 上的 Road、Teleport System、Laser System。
- RoadGenerator 上的 Level Data、Player 和各类 Prefab。
- GameManager 上的 Player、Ui Canvas、Bgm。
- BackgroundController 上的背景图片、小球 MeshRenderer 和七份小球材质。
- 各道具预制体根节点上的 PropArt、Palette 与 Glass Material；玻璃面及传送光团使用透明材质。

## 关卡 JSON 格式

下面仅用于说明数据结构：

    {
      "id": "example",
      "duration": 121,
      "forwardSpeed": 6,
      "tileSize": 2,
      "columns": 5,
      "rowCount": 364,
      "defaultGround": "11111",
      "segments": [
        {
          "startRow": 0,
          "ground": [
            "11111",
            "01110",
            "00100"
          ]
        },
        {
          "startRow": 3,
          "repeat": 361,
          "ground": [
            "11111"
          ]
        }
      ],
      "mountains": [
        { "row": 20, "col": 2 }
      ],
      "teleports": [
        { "row": 30, "col": 1 }
      ],
      "lasers": [
        { "row": 50, "col": 3 }
      ],
      "diamonds": [
        { "row": 10, "col": 2 }
      ],
      "crowns": [
        { "row": 60, "col": 1 }
      ]
    }

### 坐标约定

- 行号 `row` 从 `0` 开始，沿前进方向增加。
- 列号 `col` 从左到右为 `0～4`。
- `ground` 每条字符串必须恰好包含五个字符。
- 空白行和缩进不影响行号。
- 插入或删除一条地板字符串，会改变本段后续地板对应的行号。
- 独立物体坐标不会随地板字符串的增删自动调整。

格子长度为 `tileSize` 时：

    X = (col - 2) × tileSize
    Z = -row × tileSize

### 路段配置

- `startRow`：本段开始的行号。
- `ground`：本段地板布局。
- `repeat`：重复整个 `ground` 数组的次数，省略时为一次。
- `defaultGround`：未被任何路段配置覆盖的行使用的布局。

各路段不能重叠，也不能超过 `rowCount`。

### 收集物高度

钻石和皇冠支持可选的 `height` 字段：

    { "row": 120, "col": 2, "height": 3.5 }

`height` 表示收集范围中心相对于道路基准面的高度，模型随之移动。

### 编辑注意事项

- JSON 数组和对象的最后一项后面不能加逗号。
- 不要在 JSON 中添加注释。
- 地板字符目前仅支持 `0、1、3、5`。
- 原来的山峰字符 `2`、传送字符 `6` 已改为独立坐标列表。
- 大玻璃砖字符 `4` 当前未实现。
- 修改资源时保留对应 `.meta` 文件，避免场景和预制体引用丢失。

## 参数调整

已有组件的实际运行参数以 Cocos 属性检查器中的值为准。

修改 TypeScript 中的属性默认值，不会自动覆盖场景里已经保存的属性值。调整速度、跳跃高度、玻璃坍塌时间或拾取范围时，应同步检查属性检查器。

当前关卡设计使用格子长度 `2`、前进速度 `6`。对应每秒前进三行，121 秒从第 0 行中心到达第 363 行中心。

JSON 中的 `duration` 和 `forwardSpeed` 用于记录关卡设计参数；当前玩家实际前进速度仍由 PlayerController 的 Forward Speed 决定。

道路七段配色位于 `BackgroundController.ts` 的 `floorColors` 中；小球仍使用 Main 场景原有的七份 Ball Materials。网格轮廓、边框和道具面色位于 `PropArt.ts` 中。

音乐音量首次运行时沿用场景 AudioSource 的设置（当前为 `60 / 100`）。用户调整后以保存的值为准，保存键为 `moon-in-ones-cup.music-volume`，不会在重新开始时重置。
